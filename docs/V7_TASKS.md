# v7 작업 목록

**브랜치 규칙**
- `main` — 포스터 발표 시점의 상태. `v6-poster` 태그가 그 스냅샷이다. 배포도 이 라인 기준.

- v7 작업은 전부 `v7` 브랜치에서 한다. `main`은 포스터와 운영이 걸려 있으니 건드리지 않는다.

## 포스터 발표 시 주의

포스터는 `v6-poster` 태그 시점의 결과를 쓴다. v7에서 그 수치들을 폐기하기로 했으므로(§3.4)
발표에서 다음을 조심한다.

| 발표 내용 | 상태 |
|----------|------|
| 파이프라인 구성, 서비스 구현, 데이터 수집 규모 | 문제 없음 |
| 종 분류(SO) 정확도 | 점 추정으로는 유효. **95% CI를 반드시 병기** (n=199에서 ±6.2%p) |
| 모델·전처리 간 우열 | **주장하지 말 것.** 5%p 차이 검출력이 35%라 순위가 통계적으로 성립하지 않음 (§12.1) |
| 멀티태스크(SX/FO/MT) 효과 | **주장하지 말 것.** 성별·형태 라벨 32.7%가 유실된 채 학습됨 (§4.3) |
| bbox/seg 전처리 결과 | **주장하지 말 것.** 조각 이미지 309장 혼입 (§4.8) |

질문을 받으면 "재검증 중이며 v7에서 통제된 조건으로 다시 측정한다"가 정확한 답이다.
결함을 먼저 밝히는 편이 방어에 유리하다.
